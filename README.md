# Vocab-Invaders
Ein Vokabel-Spiel für den Englischunterricht im Stil von Space Invaders. Von oben schweben Wörter herab, das Schiff schießt die richtige deutsche Übersetzung ab. Läuft im Browser auf dem Schul-iPad und am PC, ohne Installation, ohne Server, ohne externe Bibliotheken. Dient zum Wiederholen, nicht zum Einführen neuer Vokabeln.
